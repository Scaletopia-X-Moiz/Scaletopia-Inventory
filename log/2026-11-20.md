# 2026-11-20

- Added **open tags**: a free-form, GHL-style tags field in the import wizard, stored
  in a new `open_tags text[]` column on `companies`, `people` and `import_jobs`
  (GIN indexes on the first two). It is separate from the fixed `[client, niche,
  date]` `tags` because `nichesFromTags` treats any unknown tag as a niche.
  Re-imports merge (union) open tags into existing rows and never overwrite.
- Companies and People got a **Tags filter** (URL params `tags` / `tags_exclude`).
  The filter lives in Postgres, so `openTags {include, exclude}` was added to all
  six filter RPCs, and the two `*_filter_options` RPCs return an `openTags` facet.
  SQL is `lib/data/open-tags.sql`, patched from the live function bodies;
  rollback is `lib/data/open-tags-rollback.sql`. The migration was applied to
  production by hand on 2026-11-19/20 and must not be run again.
- Import **Client** is now a required dropdown of active clients (plus "All
  clients"), so nobody can misspell a client name.
- Verified: `tsc --noEmit` clean; the open-tags, import-jobs, import-jobs API and
  import-worker tests pass (66). Not run: the live-DB suites (`import-tick`,
  `esp-filter`, `companies`, `people`), which fail or hang without a live DB and
  were already failing before this change.
- Still to do after deploy: queue one real import to confirm open tags land on
  new rows and merge on re-import.

## Client dropdown now reads Airtable (2026-11-21)

- The Client dropdown first read the databank `clients` table, which is the push-credential list (Secondary GHL accounts, test accounts, churned clients). It now reads Airtable Operations & Data Analytics > Clients where `Client Status` = Active, via `/api/clients/import-options`. The push pickers still use `/api/clients/active`.
- Needs `AIRTABLE_TOKEN` in Vercel production (added 2026-11-21, redeployed). Without it the route returns 503 and imports are blocked.
- Verified live: dropdown shows All clients + the 10 Active clients (Acceler8, Dtco, Go Fish Digital, Growth Lab, Kodif, Kynship, Redo, Scaletopia, Score More Clients, Wise Digital Partners).
- Airtable spells it "Dtco" (the databank row said "DTCo"), so new imports tag "Dtco".
